# Public Data Set

This folder contains the two public FJSP families used by the makespan-only external validation.

- `Brandimarte/`: MK01-MK10, Brandimarte (1993), standard FJSP format.
- `Lawrence/`: la01-la40, Lawrence/Hurink e-data as distributed by the `fjsp-instances` repository.

The machine indices in these files are zero-based.  Brandimarte best-known values are the standard values; Lawrence values are the proven/best values recorded in the repository's `instances.json`. Missing published values are left empty rather than guessed.
